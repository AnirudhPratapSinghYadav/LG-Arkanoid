# Support for LG Arkanoid

If you need help setting up the game on your Liquid Galaxy rig, developing new features, or troubleshooting network issues, here is where you can get support:

## 1. Documentation
Always check the `docs/` folder first. We have extensively documented the architecture, networking, security, and setup processes (both mobile and rig). See `docs/troubleshooting.md` for common issues (like Node version incompatibilities).

## 2. GitHub Issues
If you've encountered a bug, have a feature request, or need clarification on the codebase, please open an issue in this repository using the provided Issue Templates.

## 3. Liquid Galaxy Community
For broader Liquid Galaxy platform questions, or to get in touch with mentors, please reach out to the Liquid Galaxy Lab community channels (Discord/Mailing List) where this GSoC 2026 project was incubated.
